Corporate Portal Dashboard — Redesign Task Brief

Solara General Insurance  ·  SolaraNxt Corporate Portal  ·  Client-facing BI dashboard for group insurance administrators

Project context
Client / Portal
Solara General — SolaraNxt
Group ID
GRP-00142
Primary user
Corporate insurance admin / broker
Platform
Web (desktop-first)

The current portal homepage presents a marketing banner with no operational data visible on load. Users must navigate multiple sub-menus to access any meaningful business intelligence. The goal is to redesign the homepage into a functional command dashboard.

Problems identified (current state)

Homepage is a marketing banner — zero operational data on load

No LOB-wise split visible anywhere on the main view

Claims ratio, renewal alerts & policy expiry require deep navigation

No MTD / YTD toggle — time-period comparison buried or absent

No GWP business split chart or downloadable reports on home

Poor visual hierarchy — navigation bar and sidebar compete for attention

Lines of business (LOB) scope
Motor Health / GMC Fire / Property Travel Marine + any others active for the client group
Functional requirements — what the dashboard must show
1
Total number of policies (NOP) — active, LOB-wise
With MTD and YTD toggle. Each LOB shows its own NOP count side by side.
2
Claims ratio overview — LOB-wise
MTD and YTD. Show incurred vs premium ratio. Flag LOBs above threshold.
3
Renewal due summary — LOB-wise (till date)
Policies due for renewal. Split by LOB. Show overdue vs due-soon status.
4
Policy expiry alerts (till date)
Expiring in 7, 15, and 30 days. Alert panel with count and quick-action link.
5
LOB-wise business split — GWP (Gross Written Premium)
Visual chart — donut or bar — showing premium contribution per LOB. Filterable by date range.
6
Downloadable summary report
One-click export of dashboard snapshot in PDF and Excel. Accessible from header or dashboard footer.

Deliverables checklist
📊  High-fidelity dashboard mockup (Figma)
Desktop viewport (1440px wide). All 6 functional requirement modules visible above the fold or within one scroll. Two states: default view + MTD/YTD toggled.
🗺  Revised information architecture
Simplified nav map showing how the new dashboard fits into the existing portal structure. Highlight removed or collapsed menu items.
🧩  Annotated component spec sheet
Key dashboard components (LOB card, claims ratio widget, alert panel, GWP chart, export button) with states, hover interactions, and data labels described.
📋  UX audit report (1–2 pages)
Current-state heuristic findings, prioritised issue list (Critical / High / Medium), and rationale for design decisions in the new layout.
♿  Accessibility compliance notes
Contrast ratios, WCAG 2.1 AA compliance check for all colour choices, keyboard navigation path for the dashboard.
Acceptance criteria
Visibility
All 6 functional modules visible without login re-navigation
Time to insight
User reads NOP + claims ratio in under 10 seconds on load
LOB toggle
MTD / YTD switch updates all 6 modules simultaneously
Export
Download action reachable in 1 click from dashboard
Accessibility
All text elements pass WCAG 2.1 AA (4.5:1 contrast)
Figma
Shared Figma file with auto-layout components, properly named
Design constraints & guidelines
🎨
Retain client brand colours: primary blue #003DA5, accent orange #F07A0C
🖥
Desktop-first (1440px), responsive down to 1280px minimum. Mobile is out of scope for this sprint.
📊
Use placeholder / dummy data for all charts and metrics — no real client data required.
👤
Primary persona: corporate HR / insurance admin. Secondary: broker managing multiple groups.
🚫
Do not redesign the full portal — scope is the dashboard homepage only. Navigation bar changes must be additive, not destructive.
